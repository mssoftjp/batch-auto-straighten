# Security Policy

## Supported versions

Only the latest GitHub Release receives security fixes.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/mssoftjp/batch-auto-straighten/security/advisories/new) for this repository. Do not include private photos, catalog files, credentials, or personal information in a public issue.

Include the affected release, macOS and Lightroom Classic versions, the observed behavior, and minimal reproduction steps. Reports are reviewed before public disclosure.
