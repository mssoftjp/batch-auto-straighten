Batch Auto Straighten

Lightroom Classic · Apple silicon · macOS 26 or later

English · 日本語

Installation

  1. Copy BatchAutoStraighten.lrplugin from this disk to a folder on your Mac where it can stay, such as a Lightroom Plug-ins folder in your home folder.
  2. In Lightroom Classic, choose File → Plug-in Manager, click Add, and select the copied plug-in.
  3. Make sure it is enabled, then click Done. You can now eject this disk.
  4. Select photos and choose Library → Plug-in Extras → Batch Auto Straighten (also under File → Plug-in Extras).
  5. Check the settings, click Straighten Photos, and review the results. Hover over any control for a short explanation.

Copy first, then register.
A plug-in registered from this disk stops working once the disk is ejected. Double-clicking the plug-in does not install it.

To update, quit Lightroom Classic, replace the old copy with the new one, then reopen Lightroom Classic and check the version in Plug-in Manager.

The plug-in appears in English, or in Japanese when Lightroom Classic is set to Japanese. For the full guide, see the README on GitHub. Without an internet connection, Control-click the copied plug-in, choose Show Package Contents, and open README.md.

インストール（日本語）

  1. このディスク内の BatchAutoStraighten.lrplugin を、今後移動しないMac上のフォルダ（例: ホームフォルダ内の Lightroom Plug-ins フォルダ）へコピーします。
  2. Lightroom Classicで ファイル → プラグインマネージャー を開き、追加 をクリックしてコピーしたプラグインを選びます。
  3. 有効になっていることを確認し、完了 をクリックします。これでこのディスクは取り出せます。
  4. 写真を選択し、ライブラリ → プラグインエクストラ → Batch Auto Straighten を選びます（ファイル → プラグインエクストラ からも開けます）。
  5. 設定を確認して 角度を補正 をクリックし、終わったら結果を確認します。各項目にポインターを合わせると説明が表示されます。

コピーしてから登録してください。
このディスクから直接登録すると、ディスクを取り出したときに使えなくなります。プラグインをダブルクリックしてもインストールされません。

更新するとき は、Lightroom Classicを終了してから古いプラグインを新しいものに置き換えます。Lightroom Classicを起動し、プラグインマネージャーでバージョンを確認してください。

Lightroom Classicの表示言語が日本語なら日本語で、それ以外は英語で表示されます。詳しい使い方は GitHubのREADME を参照してください。インターネットに接続していない場合は、コピーしたプラグインをControlキーを押しながらクリックし、パッケージの内容を表示 を選んで README.md を開きます。
